# The work is not the address

A publication should be something you can hold onto. A file you can send to a friend, save on a drive, or find somewhere new.

The words are yours. The copy should be, too.

## One file. Many possibilities.

This is a real signed Presskeep document. Save it to your computer and open it in an ordinary browser. Its text, styling, and proof of authorship travel together.

You can also open it in Presskeep to verify the signature and check that it matches the safe document template.

> A good story deserves a life beyond the place you first published it.

This sample uses a demonstration publication identity. It illustrates the file format; it is not a follow code for an active publication.
