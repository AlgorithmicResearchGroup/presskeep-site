# Presskeep

**Your words. Here to stay.**

The public website and purchase home for Presskeep, a desktop app for signed,
portable publishing.

Visit **https://algorithmicresearchgroup.github.io/presskeep-site/**.

## Website

This is a dependency-free static site with a locally hosted Space Grotesk font,
an accessible publishing walkthrough, and a real signed sample document. The
font's SIL Open Font License is included in `assets/fonts/OFL.txt`.

To preview this directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Downloads

Buy Presskeep for **US$9.99 once** at
[the ARG store](https://store.arg.studio/#presskeep). After checkout, the store
provides a private download for the signed and notarized universal Mac installer.
It supports Apple Silicon and Intel Macs running macOS 11 or later. Installer
checksums are linked from the purchase download page.

## Sample document

`samples/the-work.presskeep.html` is a complete, signed Presskeep document.
Download it and open it in any ordinary browser, or use Presskeep to verify it.
It uses a demonstration publication identity and is not an active publication.
